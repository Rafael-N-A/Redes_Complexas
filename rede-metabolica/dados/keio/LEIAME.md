# Gabarito: genes essenciais da coleção Keio

A lista não vem da API do KEGG. Ela sai do material suplementar de:

> Baba et al. (2006). Construction of *Escherichia coli* K-12 in-frame,
> single-gene knockout mutants: the Keio collection. *Mol. Syst. Biol.*

Converta a tabela suplementar para `essenciais.csv`, nesta pasta, com uma
coluna `gene` contendo o b-number de cada gene candidato a essencial:

```
gene
b0001
b0002
...
```

Anote aqui de qual tabela suplementar a lista saiu e quantos genes ela tem
(Baba et al. relatam 303 candidatos a essenciais).
